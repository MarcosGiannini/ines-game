# Inés

> 2D fast-paced platformer about movement, imagination, and overcoming fear.  
> Inspired by a real child. Built with Godot 4.

---

## What is this game?

**Inés** is a movement-driven 2D platformer where the player controls a 6-year-old girl who never stops moving.

The core loop is simple:

```
MOVE → JUMP → CHAIN → FLOW
```

Through movement, Inés transforms darkness into light, fears into friends, and ordinary places into playgrounds of imagination. There are no weapons. There is no violence. There is only motion.

---

## Character

**Inés** — 6 years old. Side ponytail with a pink hair tie. Pink outfit. Barefoot. Always jumping. Always moving.

## Design Principles

- **The player must not stop.** Standing still is unnatural.
- **Movement is the power.** All abilities come from motion.
- **Transformation, not destruction.** Enemies change, they don't die.
- **Safe for everyone.** No violence, no weapons, no frightening content.
